# integralivre-docs

Documentação **de usuário** da plataforma Integralivre BESS, publicada em
GitHub Pages via VitePress.

> Este repositório contém somente conteúdo público (guia de uso, FAQ).
> Documentação técnica não é publicada aqui.

## Desenvolvimento local

```bash
pnpm install
pnpm dev
```

O deploy é automático: todo push na branch `main` builda e publica o site no
GitHub Pages.
